# PAM — Лабораторная работа 1: среда разработки, основы Dart, выбор темы

Дисциплина PAM (Программирование мобильных приложений), UTM FCIM.
Автор: Трачук Анастасия, TI-236.

Продолжение — проект BizMatch (L2–L5): [PAM-BizMatch](https://github.com/anastasia56yy/PAM-BizMatch).
PDF-отчёт — в [релизе L1](https://github.com/anastasia56yy/PAM-L1/releases/tag/L1).

## Содержимое

| Папка | Что внутри |
|---|---|
| `hello_pam/` | первый Flutter-проект (`flutter create`): запуск на эмуляторе, hot reload и hot restart |
| `l1_dart/exercises.dart` | упражнения E1–E6 по Dart: null safety, коллекции, именованные параметры, классы, mixin, async |
| `l1_dart/mini_spec_BizMatch.md` | мини-спецификация темы проекта: аудитория, экраны, сущности |
| `evidence/` | вывод `flutter doctor`, `flutter devices`, результат упражнений, скриншоты приложения |

## Запуск

```
cd l1_dart
dart run exercises.dart
```
```
cd hello_pam
flutter pub get
flutter run
```
